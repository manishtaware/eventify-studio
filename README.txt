Eventify Studio - Multi-Page Website

Pages:
- index.html -> Home
- categories.html -> Categories
- events.html -> Concerts & Shows
- venues.html -> Venues
- gallery.html -> Gallery
- calendar.html -> Calendar
- blogs.html -> Blogs
- dashboards.html -> Dashboards
- organize.html -> Organize Event
- contact.html -> Contact

All pages share the original styling, libraries, booking/PDF/email JavaScript and content.

For permanent public hosting, upload this folder to GitHub and enable GitHub Pages, or deploy it to Netlify/Vercel.
