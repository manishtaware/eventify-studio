Step-by-step chronological runtime flow of a ticket reservation transaction.

End-to-End Pipeline
1
Modal Initialization & Dynamic Seat Lock Fetch

User clicks "Select Seats". openSeatModal() queries localStorage for getShowBookedSeats(showName). Any previously booked seats are merged with default pre-booked seats and rendered in gray as unclickable.

2
Seat Selection & Anti-Scalping Constraint Check

User toggles seats (e.g. A1, A2). toggleSeat() validates that selectedSeats.length <= 8. Attempting to choose a 9th seat triggers an immediate alert boundary.

3
Promo Code Discount Application

User inputs coupon PUNE2026. applyPromoCode() verifies cart threshold and deducts ₹200 live from the itemized checkout breakdown.

4
Input Sanitization (XSS Defense) & Atomic Commit

User submits attendee details. Strings pass through escapeHtml(). addShowBookedSeats() commits the seat IDs to storage, permanently locking them for that show.

5
QRCode.js Canvas Synthesis & jsPDF Pass Download

Generates a scannable verification QR Code data URL and writes an official e-ticket pass with gate-entry security marks, downloading immediately to the user's computer.

6
Real-Time Organizer Telemetry & Calendar Sync

Fires background FormSubmit email, wires up 1-click Google Calendar sync, and notifies loadOrganizerDashboard() to increment revenue and render the attendee in the roster table.

Finite State Machine (FSM): Transitions and lifecycle states of individual seats and digital tickets.

1. AVAILABLE
Default state. Seat can be clicked. Displayed in light gray.
2. SELECTED
Active in user cart (1 to 8 seats). Displayed in bright green.
3. IN CHECKOUT
Held during attendee form entry & promo code calculation.
4. BOOKED / OCCUPIED
Committed to storage. Permanently gray & disabled across modals.
5. RELEASED
Triggered via "Cancel Pass" in Wallet. Reverts to AVAILABLE.
💡 State Reversibility Guarantee:

When an attendee clicks "Cancel Pass" in dashboards.html, the state engine calls removeShowBookedSeats(), purging the seat numbers from storage, incrementing the show's capacity badge, and returning those seats to the AVAILABLE pool with zero page reload.
